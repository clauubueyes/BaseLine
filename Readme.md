# 🎾 BaseLine

BaseLine es una aplicación web sobre tenis pensada para aprender sobre este deporte,
descubrir jugadores, seguir competiciones y compartir la afición con otros usuarios.

El proyecto está actualmente en desarrollo.

## 🎯 Objetivo

Crear una plataforma sencilla y accesible para aficionados al tenis, tanto para personas
que están empezando como para quienes ya siguen habitualmente este deporte.
